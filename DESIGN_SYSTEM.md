## 1. Принципы дизайна

### 1. Спокойствие прежде всего
Приложение живёт на фоне рабочего дня. Интерфейс не должен конкурировать за внимание — он приглашает, а не кричит. Никаких агрессивных цветов, резких переходов, мигающих элементов.

### 2. Одно действие на экране
В любой момент пользователь видит одну главную задачу: таймер идёт → один CTA (пауза). Идёт перерыв → одно упражнение. Не перегружаем экран вариантами.

### 3. Пространство дышит
Щедрые отступы важнее компактности. Элементы не должны «давить» друг на друга. Минимум 16px между логическими блоками, 32px между секциями.

### 4. Цвет несёт смысл
Зелёный = действие завершено или здоровье. Оранжевый = внимание, мало времени. Красный = критически мало. Синий = информация. Цвета никогда не используются декоративно — только функционально.

### 5. Анимации помогают ориентироваться
Каждая анимация объясняет пространственные отношения: что откуда появилось, куда ушло. Длительность 150–300ms. Нет анимаций ради эффекта.

### 6. Доступность не опциональна
Минимальный контраст текста 4.5:1 (WCAG AA). Все интерактивные элементы достижимы с клавиатуры. Все диалоги содержат `aria-label` и `role`. Фокус-кольцо всегда видимо.

### 7. Тёмная и светлая темы равнозначны
Дизайн проверяется в обеих темах. oklch-цвета адаптированы отдельно — не просто инвертированы. Контрасты соблюдены в каждой теме независимо.

### 8. Типографика — каркас иерархии
Не более трёх размеров текста на одном экране. Размер и насыщенность определяют важность, цвет — роль (основной / вспомогательный / подсказка).

### 9. Состояния компонентов полны
Каждый компонент имеет: `default`, `hover`, `focus`, `disabled`, `loading`, `error`. Нет «висящих» состояний без визуального отклика.

### 10. Консистентность через токены
Никаких magic numbers в коде. Все значения — из системы токенов: `--spacing-*`, `--radius`, `--color-*`. Новый разработчик должен суметь создать новый экран, не нарушив стиль.

## 2. Цветовая палитра

> Все цвета в формате oklch(lightness chroma hue). Значения в CSS переменных.

### 2.1 Акцентная шкала (Primary — зелёный)

Оттенок hue 160° — мятно-зелёный. Ассоциируется с здоровьем, природой, перерывом.

| Токен | oklch (светлая) | oklch (тёмная) | Применение |
|-------|-----------------|-----------------|------------|
| `--primary` | `0.55 0.15 160` | `0.65 0.15 160` | Кнопки CTA, прогресс-кольцо, активные элементы |
| `--primary-foreground` | `0.98 0.005 240` | `0.12 0.01 240` | Текст поверх primary |
| `--accent` | `0.65 0.12 160` | `0.55 0.12 160` | Второстепенные акценты, hover-эффекты |
| `--ring` | `0.55 0.15 160` | `0.65 0.15 160` | Фокус-кольцо |

```css
/* Пример использования */
.btn-primary { background: var(--primary); color: var(--primary-foreground); }
.focus-ring  { outline: 2px solid var(--ring); outline-offset: 2px; }
```

---

### 2.2 Нейтральная шкала

Оттенок hue 240° — холодный серый с лёгкой синевой. Не раздражает глаз при долгой работе.

| Токен | oklch (светлая) | oklch (тёмная) | Применение |
|-------|-----------------|-----------------|------------|
| `--background` | `0.98 0.005 240` | `0.12 0.01 240` | Фон страницы |
| `--foreground` | `0.15 0.01 240` | `0.95 0.005 240` | Основной текст |
| `--card` | `1.00 0 0` | `0.16 0.01 240` | Фон карточек |
| `--card-foreground` | `0.15 0.01 240` | `0.95 0.005 240` | Текст на карточках |
| `--muted` | `0.92 0.01 240` | `0.22 0.01 240` | Приглушённый фон (чипы, теги) |
| `--muted-foreground` | `0.50 0.01 240` | `0.60 0.01 240` | Подсказки, лейблы, плейсхолдеры |
| `--border` | `0.90 0.01 240` | `0.25 0.01 240` | Границы элементов |
| `--input` | `0.92 0.01 240` | `0.22 0.01 240` | Фон полей ввода |

### 2.3 Семантические цвета

| Токен | oklch | HEX ≈ | Смысл |
|-------|-------|--------|-------|
| `--destructive` | `0.55 0.20 25` | `#c94b2b` | Ошибка, удаление |

| `--success-foreground` | `0.98 0.005 240` | `#f8f9fc` | Текст поверх success |

## 5. Радиусы скругления

Базовый радиус: `--radius: 0.75rem` (12px).

| Токен / Класс | px | Применение |
|---------------|----|------------|
| `rounded-sm` / `rounded` | 6 | Бейджи, чипы статусов |
| `rounded-lg` | 8 | Поля ввода, маленькие карточки |
| `rounded-xl` (`--radius`) | 12 | Карточки, диалоги, большинство компонентов |
| `rounded-2xl` | 16 | Экран разминки, GIF-контейнер |
| `rounded-full` | 9999 | Кнопки Play/Pause, аватары, прогресс-пилюли |

**Правило последовательности:** чем крупнее элемент, тем больше радиус. Маленький чип — `rounded`, большая карточка — `rounded-xl`, кнопка-круг — `rounded-full`.

## 6. Компоненты

### 6.1 TimerDisplay

**Назначение:** главный элемент интерфейса — круговой таймер обратного отсчёта.

**Анатомия:**
- Внешний трек (серый) — полный круг `--muted`
- Внутренний прогресс — убывает по часовой стрелке, цвет зависит от времени
- Цифры в центре — `font-mono`, `tabular-nums`, `font-light`
- Подпись — `text-xs uppercase tracking-widest`

**Состояния:**

| Оставшееся время | Цвет кольца | Цвет цифр |
|------------------|-------------|-----------|
| > 5 мин | `text-primary` | `text-foreground` |
| ≤ 5 мин | `text-orange-400` | `text-orange-400` |
| ≤ 1 мин | `text-red-500` | `text-red-500` |
| Пауза | без изменений | без изменений |

**Размер:** SVG `256×256`, внешний круг `r=110`, stroke `6px`.

### 6.4 Input / Textarea

Стандартные поля из `shadcn/ui`. Правила:

- Всегда сопровождаются `<Label>` через `htmlFor`
- Ошибки валидации — `text-xs text-destructive` сразу под полем
- Состояние ошибки — `border-destructive` на самом поле
- `autoComplete` всегда указан (помогает менеджерам паролей)
- `Textarea` — `resize-none` (не ломает лейаут)

### 6.6 Dialog / Modal

Все модальные окна следуют правилам:

1. **`DialogTitle` всегда присутствует** — обязательно для Radix/доступности. Если визуально скрыт — `className="sr-only"`.
2. **`DialogDescription` всегда присутствует** — описывает назначение диалога.
3. Нет `AnimatePresence` / `motion.*` внутри `<Dialog>` — это вызывает ошибку `insertBefore` в Radix.
4. Анимации входа — через `animate-in fade-in duration-150` (CSS, не framer-motion).
5. Закрытие — через `onOpenChange={(o) => !o && onClose()}`.

### 6.7 ProgressRing

SVG-компонент кругового прогресса. Используется в таймере и карточке упражнения.

**Параметры:**
- Радиус задаётся явно: `r` в `viewBox`
- `strokeDasharray = 2πr`
- `strokeDashoffset = strokeDasharray × (1 − progress)`
- `transform: rotate(-90deg)` — начало в 12 часов
- `strokeLinecap="round"` — закруглённые концы

```tsx
const circumference = 2 * Math.PI * r;
const offset = circumference * (1 - progress / 100);
```

### 6.8 DropdownMenu (User Menu)

Выпадающее меню пользователя содержит строгую иерархию:

## 7. Темизация

### 7.1 Переключение темы

Реализовано через `next-themes` + `ThemeProvider`:

```tsx
<ThemeProvider attribute="class" defaultTheme="system" enableSystem>
  {children}
</ThemeProvider>
```

Тема хранится в `localStorage` как `theme: "light" | "dark" | "system"`.

### 7.2 Реализация CSS переменных

Все цвета — oklch. Это даёт:
- **Перцептивную равномерность** — `L=0.5` всегда воспринимается как "средний" яркости
- **Предсказуемые тени** — `primary/10`, `primary/20` работают предсказуемо
- **Легкую адаптацию** — смена `L` даёт светлый/тёмный вариант без изменения оттенка

```css
:root {
  --primary: oklch(0.55 0.15 160);  /* светлая тема */
}
.dark {
  --primary: oklch(0.65 0.15 160);  /* тёмная — только L изменён */
}
```

### 7.3 Правила использования цветов в коде

```tsx
// ✅ Правильно — токены
className="bg-primary text-primary-foreground"
className="border-border text-muted-foreground"

// ✅ Правильно — семантические цвета Tailwind для статусов
className="text-orange-400"    // предупреждение
className="text-green-500"     // успех
className="bg-blue-500/15"     // фон категории

// ❌ Неправильно — hardcoded значения
className="bg-[#2ea55e]"
style={{ color: "#666" }}
```
