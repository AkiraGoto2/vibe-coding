# Break Reminder

Десктопное приложение для напоминаний о перерывах с упражнениями.

## Быстрый старт

### 1. Установка зависимостей

```bash
pnpm install
```

### 2. Настройка окружения

```bash
cp .env.example .env
```

Отредактируй `.env`:
- `DATABASE_URL` — оставь как есть для SQLite
- `JWT_SECRET` — **обязательно** замени на случайную строку:
  ```bash
  openssl rand -base64 32
  ```
- `SMTP_*` — опционально, для отправки писем из формы обратной связи

### 3. Инициализация базы данных

```bash
pnpm db:push
```

Это создаст файл `prisma/dev.db` со всеми таблицами.

### 4. Запуск

```bash
pnpm dev
```

Открой http://localhost:3000

## База данных

| Таблица        | Описание                        |
|----------------|---------------------------------|
| `User`         | Пользователи                    |
| `UserSettings` | Настройки (раб./перерыв, язык)  |
| `Session`      | JWT-сессии (для ревокации)      |
| `Feedback`     | Сообщения из формы обратной связи|

Просмотр данных в браузере:
```bash
pnpm db:studio
```

## Безопасность

- Пароли хешируются **bcrypt** (cost 12)
- Сессии хранятся в **HTTP-only cookie** (защита от XSS)
- Защита от **timing attacks** при входе
- Валидация всех входных данных через **Zod**
- Параметризованные запросы через **Prisma** (защита от SQL-инъекций)
- **CSRF** защита через `sameSite: lax` cookie

## Роль администратора

### Назначение администратора

После регистрации запусти в терминале:

```bash
pnpm make-admin your@email.com
```

Затем выйди и войди снова — в меню появится ссылка **"Панель администратора"**.

### Что доступно в панели

- Статистика: пользователи, всего сообщений, новые, решённые
- Список всех сообщений обратной связи с поиском и фильтром по статусу
- Просмотр полного текста сообщения
- Смена статуса: Новое → Прочитано → Решено
- Удаление сообщений
- Прямая ссылка на email отправителя (mailto:)

### Безопасность

- Маршруты `/api/admin/*` проверяют роль `ADMIN` на сервере через JWT
- Страница `/admin` делает редирект на главную для не-администраторов
- Роль нельзя изменить через интерфейс — только через CLI скрипт
