# Break Reminder

Приложение для напоминаний о перерывах с упражнениями, авторизацией и панелью администратора.

## ⚡ Быстрый старт (3 команды)

```bash
pnpm install       # установка зависимостей
pnpm db:setup      # создание базы данных (ОБЯЗАТЕЛЬНО перед первым запуском)
pnpm dev           # запуск на http://localhost:3000
```

> **Если видите "Server error" при регистрации/входе** — вы пропустили `pnpm db:setup`.

---

## Настройка окружения

Файл `.env` уже создан с дефолтными значениями. Для продакшена обязательно смените `JWT_SECRET`:

```bash
# Сгенерировать безопасный секрет:
openssl rand -base64 32
```

Замените в `.env`:
```
JWT_SECRET="вставьте-сюда-ваш-секрет"
```

SMTP-настройки опциональны — без них письма сохраняются только в БД.

## База данных

```bash
pnpm db:setup    # создать / обновить схему БД
pnpm db:studio   # открыть визуальный редактор на localhost:5555
```

Таблицы: `User`, `UserSettings`, `Session`, `Feedback`

## ExerciseDB API (опционально)

Для получения более 1300 упражнений с анимациями от ExerciseDB:

1. Зарегистрируйтесь на [RapidAPI](https://rapidapi.com/justin-WFnsXH_t6/api/exercisedb)
2. Подпишитесь на ExerciseDB (есть бесплатный план — 10 запросов/день)
3. Скопируйте ваш API ключ
4. Добавьте в `.env`:
   ```
   EXERCISEDB_API_KEY="ваш-ключ-здесь"
   ```

Без ключа приложение использует 12 встроенных упражнений. Упражнения выбираются автоматически — только те, что можно делать за/у стола (bodyweight + band).

## Роль администратора

После регистрации аккаунта назначьте его администратором:

```bash
pnpm make-admin your@email.com
```

Выйдите и войдите снова → в меню появится **Панель администратора**.

## Структура проекта

```

  api/auth/          — регистрация, вход, выход, текущий пользователь
  api/settings/      — сохранение настроек
  api/feedback/      — форма обратной связи
  api/admin/         — API панели администратора (только для ADMIN)
  admin/             — страница панели администратора

  auth.ts            — JWT, сессии, bcrypt
  db.ts              — Prisma клиент
  validations.ts     — Zod схемы
  i18n.ts            — переводы EN/RU
hooks/
  use-auth.ts        — контекст авторизации
  use-language.ts    — смена языка
prisma/
  schema.prisma      — схема БД
scripts/
  make-admin.ts      — CLI для назначения администратора
```

## Безопасность

| Угроза | Защита |
|--------|--------|
| Перехват паролей | bcrypt hash, cost 12 |
| XSS | HTTP-only cookie, недоступна из JS |
| Timing attacks | Всегда сравниваем hash, даже если email не найден |
| SQL-инъекции | Prisma параметризованные запросы |
| CSRF | `sameSite: lax` cookie |
| Невалидные данные | Zod на каждом endpoint |
| Несанкционированный доступ к /admin | Проверка роли в JWT на сервере |
